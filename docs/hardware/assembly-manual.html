0开始之前（顺序不能乱）

接线/焊线 → 刷固件 → 桌面调中位 → 机械装配 → 装壳 → 向导校准 → 验收
  • 电子件和舵机先在桌面上接好、刷好固件；装配期间电子件不入壳，直到 §12。
  • 中位流程：只插一个舵机 → 上电 → 连 TinyEngineer-XXXX → http://192.168.4.1/config → Move all to 90° → 拔掉舵机线再继续装。
  • 工具：PH0/PH1 螺丝刀、M2 螺丝套装、5V/≥2A 电源、USB-C 数据线、镊子。
红线：中位阶段绝对不要完成 Wi-Fi 向导。舵机范围、OLED、LED、音量、家庭 Wi-Fi 全部留到装完壳的 §20。

§1Head —— OLED + 1 号舵机

  1. 撕掉 OLED 保护膜。
  2. 先把 OLED 排线插上，再把它放进头壳（装进去后手够不到接口）。
  3. 取 1 个舵机（先不装舵盘，方向随意），与 OLED 一起放进 Head 仓位。
  4. 两根线从壳体两侧开口引出，卡进头壳背面的线卡。

§2Hat

  • Hat 扣在头上，2× M2×8。拧进塑料即可，别过拧。

§2a中位窗口（关键流程）

  • 电子件留在桌上。给当前舵机做中位（见 §0），做完拔线。
  • 后面每个“中位”步骤都照此办理：中位 → 装件 → 拔线。

§3Neck

  1. 第 2 个舵机（不装盘）→ 中位。
  2. Neck 压到舵机轴上，与舵机本体垂直；中部凸起朝舵机长端（线缆侧 = 背面）。
  3. 用舵机自带螺丝固定。
  4. 六角槽放 1× M2 螺母：用大孔那个槽（机器人右侧）；小孔槽留空。
  5. 拔线。

§4Neck 与 Head 合体

  1. 给头里的舵机做中位。
  2. 两段式：先让 Neck 套上头部舵机轴 → 再往里推，直到螺母侧与 Head 齐平、侧面安装孔对正。
  3. 90° 时 Neck 必须垂直于 Head，不对就先调再拧。
  4. 固定：机器人右侧 M2×8 拧进captured 螺母；左侧用舵机自带螺丝。
  5. 拔线。

§5Chest —— 两侧舵机

  1. Chest 左右侧仓各放 1 个未用舵机（不装盘，方向随意）。
  2. 每根线从前部竖直隧道穿下去，从底部出来。
  3. 每个舵机 2 颗，共 4× M2×16，别过拧。

§6头组件装到 Chest

  1. Neck 上那颗舵机进 Chest 中央仓。
  2. 先穿线（中央隧道 → 底部）再坐进去。
  3. 头/颈的“脸”方向与胸一致（有线隧道那一侧）。
  4. 2× M2×8（优先两颗；太紧就只上背面 1 颗）。

§7Belly —— 最后一个舵机

  1. 最后 1 个舵机 → 中位。
  2. Belly 压到舵机轴上（专用仓，不装盘）；舵机与 Belly 垂直，长端朝 Belly 圆弧侧。
  3. 舵机自带螺丝固定，拔线。

§8胸线穿 Belly 并合体

  1. Chest 底部 3 根线（颈 + 左右手）：从 Belly 上方大孔进、下方侧孔出。
  2. 保持离开 Chest 时的 左 → 颈 → 右 顺序（仅识别用，不是通道号）。
  3. Belly 圆弧朝后，贴合 Chest 轮廓，4× M2×8。

§9身体坐进 Chair

  1. Belly 舵机进 Chair 专用仓，脸朝前。
  2. 舵机线走 Chair 竖直隧道到椅子下方。
  3. SeatLeft / SeatRight 从两侧滑入卡住身体舵机（防掉落），注意别压线。
  4. 两个椅面之间 2× M2×16。

§10–11桌面堆叠 + 徽标

  1. DeskTop 嵌进 DeskPad，整体放 Desk，圆缺口朝机器人，四角 4× M2×16。
  2. AiEmblem 放桌面正面，2× M2×4。

§12电子件入壳

路线 A（主控板）

  1. 主控板坐进桌腔。
  2. 舵机、OLED 先不插（§15 才插）。
  3. 喇叭接到座子或焊盘（二选一），塞进桌腔合适位置。
  4. ESP32 先不装（§13 从桌面上方嵌）。

路线 B（模块）——用 assembly-modular.md 替换本节与 §13

  1. USB-C 分线板：4× M2×16 + 螺母固定在桌腔。
  2. PCA9685：4× M2×4 固定到桌内前壁导轨。
  3. MAX98357A：2× M2×4 固定在同一内侧壁导轨。
  4. 喇叭贴内壁/松散放。顺序：USB → PCA9685 → 功放 → 喇叭。

§13ESP32 + 上电冒烟测试 + LampBase

  1. ESP32-C3-Zero 从桌面上方嵌入：引脚穿过桌面开孔、插进下方排针；按板丝印 USB 标记定向；与桌面齐平、不凸出。
  2. 冒烟测试：确认方向 → 上电 → 灯亮 + 起 TinyEngineer-XXXX 热点 → 正常后断电。
  3. LampButton 放 LampBase 下方（从上方按 ESP32 复位键）。
  4. LampBase 开口对准状态灯，2× M2×8（同时压住 ESP32）。

§14桌面道具

  1. 笔记本：LaptopScreen 滑进 LaptopCase 底面槽，1× M2×8 从桌下拧。
  2. 杯子：Coffee 放进 Mug，同样 1× M2×8 从桌下。
  3. 铃铛：先把 M2×16 完全拧进 Bell，再从桌面上方拧下去 + 桌下 M2 螺母。

§15插回舵机 + OLED（最容易接错）

  1. 桌子前倾让排针朝上，逐根插好舵机线与 OLED 线。
  2. 通道顺序（硬性）：0 头俯仰 / 1 颈左右 / 2 左手 / 3 右手 / 4 躯干。
  3. 上电做“舵机 + OLED”冒烟测试；异常先断电再换插。
通道关节
0头（俯仰）
1颈（左右转）
2左手
3右手
4躯干（左右转）

§16Chair 与 Desk 合体

  • 桌子推近椅子，孔位对正，每侧 3 颗共 6× M2×8；别硬怼，线缆避开螺丝路径。

底盖BottomCover

  1. 先接完线、上完 6 颗侧螺丝，断电、托住翻面。
  2. 椅子的线走既有隧道进桌腔，线圈在周界内，避开 6 个螺丝孔路径，不能夹线。
  3. 用新版 Chair（后壁下方有 2 个加固盲孔）；老版无孔需重打。
  4. 底盖平面贴桌/椅，凹坑朝外；对齐 4 个桌面孔 + 2 个椅后孔。
  5. 6× M2×8 盘头/半圆头（头径 ≤4.0mm、高 ≤2.0mm），无螺母；头顶进凹坑、不凸出底面。
  6. 打印：贴合面朝下、凹坑朝上，无支撑。

§17–18手臂

  1. 左右各：ForearmLeft/ForearmRight + UpperArm，肘部 1× M2×8；打两个 UpperArm。
  2. 此步只做臂组件，先别装到胸舵机。
  3. 装之前先给两侧（手）舵机中位，再把臂组件压上舵机轴。
  4. 90° 时手在肩高、前臂朝前（朝桌）；用舵机自带螺丝固定。

§19台灯（压配，无螺丝）

  • LampCap 套 LampDiffuser → 整体压进 LampBase 开口。

§20校准与首启（向导）

  1. 上电 → 起 TinyEngineer-XXXX → 连上 → 打开 http://192.168.4.1/config。
  2. 走完向导：① 舵机安全范围（90° 状态下逐关节标 min/max）② OLED 旋转 ③ RGB 顺序（默认 GRB）④ 喇叭欢迎音 ⑤ 主机名 + 2.4GHz Wi-Fi。
  3. 完成后断电再上电，应自动连家里网络。
  4. 验证： 
    curl http://tiny-engineer.local/health
curl -X POST "http://tiny-engineer.local/anim?name=ring"
Wi-Fi 之后不能在普通 Config 页改，只能恢复出厂重新配。

§21调试手册

正常启动时序（串口 115200）

TINY ENGINEER → 版本 → I2C（SDA=GP0/SCL=GP1）→ PCA9685 @0x40 必须成功 → OLED @0x3C（失败仅警告）→ 加载设置 → 进度屏/Wi-Fi → I2S → 舵机 35°/s 缓动到中位 → ROBOT READY → HTTP 地址。

串口默认关闭（serial_log 关），无串口时靠 RGB 灯判断。

红灯闪码（致命错误，会挂起）

闪几下含义检查
1I2C 0x40 找不到 PCA9685VCC 接 3V3（不是 V+）、SDA/SCL、地址、共地
2MAX98357A / I2S 初始化失败GP2/GP3/GP4 → BCLK/LRC/DIN，别短到 5V/GND

节奏：亮 300ms / 灭 300ms，循环间隔 3s。

HTTP 自测

curl http://tiny-engineer.local/health
curl -X POST http://tiny-engineer.local/test/audio
curl -X POST http://tiny-engineer.local/test/screen
curl -X POST http://tiny-engineer.local/test/movement
curl -X POST http://tiny-engineer.local/test/led
curl -X POST "http://tiny-engineer.local/test/servo" -H "Content-Type: application/json" -d '{"index":0,"angle":90}'
/test/movement 是最耗电瞬间（五舵机同动）。若热点/串口在这一刻掉线，是欠压，不是 PWM 问题。

舵机安全范围（装好后必须遵守）

#关节动作安全范围（默认）
0头俯仰60–130°
1颈左右40–130°
2左手抬/落45–135°
3右手抬/落（反向刻度）35–125°
4躯干左右40–130°
  • 这是安装后的机械安全范围（默认值，向导可改并存入 NVS）。不要盲打 0–180°——会堵转、崩齿、拉崩 5V。
  • 找限位：setup AP 模式 /setup/servo 可用 0–180°；调好后只用安全范围。
  • 空闲 2 秒后固件释放 PWM，舵机变软（头可能下垂）——设计行为，不是故障。
  • 左右手刻度相反：左手角度大 = 抬起，右手角度大 = 落下（打字：左 max、右 min）。

§22验收清单

  • GET /health 返回 OK，OLED 显示 IP
  • POST /anim?name=ring：摇铃 + 有声音
  • 五个关节在安全范围内动作顺畅、无异响
  • 装壳后无夹线、底盖平齐、六颗螺丝到位
  • 断电重启自动连 Wi-Fi（无需重新配网）
  • （可选）npx -y tiny-engineer setup hook 能触发动作
