## 0. 定位

方案 B = **不做 PCB**，用三块市售模块替代主控板上的三个集成器件：

| 主控板上的器件 | 方案 B 用 |
| --- | --- |
| PCA9685（板载芯片） | PCA9685 16 路舵机驱动模块 |
| MAX98357A（板载芯片） | MAX98357A I2S 功放模块 |
| USB-C 口 + 保护电路 | USB-C 分线板（Adafruit 5993 或等效） |

**其余全部相同**：同一份固件、同一套打印件、同样的 ESP32 / 5 只舵机 / OLED / 喇叭 / M2 螺丝 / 5V≥2A 电源。
官方原文：*"Same firmware and printed Desk."*
对应文档：接线 `docs/hardware/wiring.md`；装机 `docs/3d/assembly-modular.md`（**替换** `assembly.md` 的 §12–13，其余 1–11、14–20 节照常）。

## 2. 关键部件规格详解

### 2.1 PCA9685 模块（选型最容易踩坑）

| 项 | 规格 |
| --- | --- |
| 作用 | 产生 5 路独立 50Hz 舵机 PWM（不用 ESP32 定时器） |
| 接口 | I2C；地址 **0x40**（A0–A5 全接地，多数模块默认就是这样） |
| PWM | 12 位；固件 `setPWMFreq(50)` |
| 双电源（**最重要**） | **VCC = 3.3V**（逻辑，来自 ESP32 3V3）；**舵机电源端 = +5V**（来自 USB VBUS）。两者绝不能并接，舵机电源绝不能取自 3V3 |
| 控制排针 | 至少 VCC / GND / SDA / SCL；**还要能接 OE**（ESP32 GP5，低有效） |
| 舵机输出 | 16×3 排针（5V/GND/SIG），本项目用通道 **0–4** |
| 上拉电阻 | Adafruit 815 板载；国产克隆板一般也有。I2C 不稳时再补 4.7 kΩ 到 3V3（`interfaces.md`：本项目不需要额外上拉） |
| OE 缺失的兜底 | 若买到没引出 OE 的简化板：① 飞线到芯片 OE 焊盘；或 ② 让 OE 常低（输出常开），然后改 `include/pins.h` 里 `PCA9685_OE_WIRED = false` 并重编固件 |
| 固件依赖 | 0x40 探测失败 = **硬失败**（挂起 + 红灯 1 闪） |

> 国产克隆板常见差异：丝印把 V+ 写成 5V、控制排针顺序不同、OE 未引出、把逻辑电与舵机电合并。**按你手上板子的丝印接线，不要按"名字"接。**

### 2.2 MAX98357A 模块

| 项 | 规格 |
| --- | --- |
| 接口 | I2S：BCLK（GP2）/ LRC（GP3）/ DIN（GP4）；**无 MCLK** |
| 电源 | Vin 2.5–5.5V ← 接 +5V；GND 共地 |
| GAIN / SD | **悬空不接**（GAIN 悬空 ≈9dB，SD 上拉 ≈ 左声道） |
| 输出 | **BTL 桥接**：SPK+ / SPK− 只接喇叭。**SPK− 不是地**，永远不要接 GND，也不要把输出送进别的功放 |
| 固件参数 | 22050Hz / 16bit / stereo slot（双声道写同样数据，芯片是单声道） |
| 喇叭接线 | 模块端子上接，或焊盘上焊 —— **二选一，不能同时** |

### 2.3 USB-C 分线板

| 项 | 规格 |
| --- | --- |
| 必须引出 | VBUS、GND、**D+、D−**（只有 VBUS/GND 的板子不够用） |
| D+ / D− | → ESP32 **GP19 / GP18**（native USB）。接了才能用这一个口完成"供电 + 刷机 + 串口" |
| CC 电阻 | 板上 5.1 kΩ×2，向充电器申请 5V（实测上限取决于充电源，常见 ~1.5A） |
| 国产"带电阻母座板" | **可以完全替代原版 5993**（电学等价）。但"带电阻"要分清：5.1 kΩ **下拉**=设备侧 ✅；56 kΩ 上拉=主机/upstream 板 ❌ 不出电 |
| 只有一颗 5.1k（只挂 CC1） | 能用但挑插头方向；补一颗到 CC2 即可（Type-C 设备要求 CC1/CC2 各一颗 Rd） |
| 电源专用板（只引 VBUS/GND，无 D±） | 能供电，但失去"一口刷机/串口"；补救：装壳前用 ESP32 自带 USB-C 刷机，装壳后只能 OTA 或开壳 |
| 验货 3 步 | ① 万用表 CC1→GND、CC2→GND 均 ≈5.1 kΩ；② 插 C-C 线量 VBUS→GND = 5V；③ 接好后先刷一次机，能认到串口即数据线也没错 |
| 机械差异 | 原版 5993 是竖立母座 + 4×M2 安装孔；国产板孔位/朝向常对不上 → 双面胶/热熔胶/自打孔固定，确保插头插得进、母座不被桌壁挡住 |
| 替代做法 | 装壳前可以只用 ESP32-C3-Zero 自带 USB-C 刷机/供电（官方允许"早期裸模块刷机"）；装了壳就没有外部口了 |
| 电源更强的做法 | 文档允许**绕过 5993**，直接用 5V/≥2A 适配器接到 +5V 与 GND 轨 |

### 2.4 ESP32-C3-Zero-M（要买排针版）

- 引出并使用：`5V`(输入 3.7–6V)、`GND`、`3V3`、`GP0`(SDA)、`GP1`(SCL)、`GP2`(BCLK)、`GP3`(LRC)、`GP4`(DIN)、`GP5`(OE)、`GP18`(D−)、`GP19`(D+)
- 板载 WS2812 状态灯 = **GPIO10**；BOOT = GPIO9；GPIO12–17 被 flash 占用不引出
- **无 USB-UART 桥**：CDC 没枚举出来时，按住 BOOT 再插 USB
- 天线区不要被金属/密实塑料压住
- 逻辑 **3.3V**，任何 5V 信号都不能直接进 GPIO

### 2.5 舵机 / OLED / 喇叭 / 电源

- **舵机**：5 只同一型号；供电只走 PCA9685 舵机排针（5V），信号由 PCA9685 输出 3.3V（该类舵机可接受）；固件脉宽窗口 800–2200µs，中位 ~1500µs
- **OLED**：SSD1306、128×32、地址 0x3C；**VCC 接 3V3**；时钟脚在微雪板上标 SCL（克隆板可能印 SCK，同一根线，接 ESP32 GP1）；OLED 缺失属软失败（不阻塞启动）
- **喇叭**：8Ω 1W；无极性要求但相位接反音质不同
- **电源**：整机共用一个标称 5V 轨；3V3 只由 ESP32 板载 LDO 供逻辑（PCA9685 VCC、OLED），**不供舵机**

## 3. 接线规格表（照抄执行）

**接线顺序（固定）：① 共地 GND → ② 信号线 → ③ 逻辑 3V3 → ④ 最后接 5V**
线色约定（官方示意）：红 = 5V，蓝 = GND，细线 = 信号。

| 从 | 引脚 | 到 | 引脚 | 用途 |

| USB-C 分线板 | 5V / VBUS | ESP32 | 5V | 板载 5V 输入 |
| USB-C 分线板 | 5V / VBUS | PCA9685 | 舵机电源端（V+ / 5V） | 舵机电源轨输入 |
| USB-C 分线板 | 5V / VBUS | MAX98357A | Vin | 功放电源 |
| USB-C 分线板 | GND | ESP32 | GND | 共地 |
| USB-C 分线板 | GND | PCA9685 | GND（逻辑侧） | 共地 |
| USB-C 分线板 | GND | OLED | GND | 共地 |
| USB-C 分线板 | GND | MAX98357A | GND | 共地 |
| USB-C 分线板 | D− | ESP32 | GP18 | native USB D−（刷机/串口） |
| USB-C 分线板 | D+ | ESP32 | GP19 | native USB D+ |
| ESP32 | 3V3 | PCA9685 | VCC | PCA9685 逻辑供电 |

**不接的东西**：MAX98357A 的 GAIN / SD；ESP32 的 GP6–GP10、GP20、GP21；C3-Zero 自带 USB-C（已用分线板时）。

### 3.2 电源结构

```
USB 5V ──→ ESP32 5V
        ├─→ PCA9685 舵机电源端(V+) ──→ 舵机 5V
        └─→ MAX98357A Vin

ESP32 3V3 ──→ PCA9685 VCC
          └─→ OLED VCC

USB GND ──→ ESP32 / PCA9685 / OLED / MAX98357A   （全部共地）
PCA9685 舵机侧 GND ──→ 舵机 GND（同一地网络）
```

### 3.3 装配后自检（官方清单）

1. 所有 GND 是同一个网络（USB、ESP32、PCA9685 两侧、OLED、功放、舵机）
2. PCA9685 **VCC ≈ 3.3V**，舵机电源端 **≈ 5V**，二者**没有短路**
3. OLED 时钟线接在 **SCL** 上
4. I2S 是 GP2/GP3/GP4 → BCLK/LRC/DIN，别和 I2C 搞混
5. 喇叭只接在 SPK+/SPK− 上

## 4. 装机（`docs/3d/assembly-modular.md`）

用这一页**替换** `assembly.md` 的 §12–13（电子件入壳），其余步骤不变、顺序不变。

1. **USB-C 分线板**：4 颗 M2×16 + 螺母固定在桌腔
2. **PCA9685**：4 颗 M2×4 固定到桌内前壁导轨
3. **MAX98357A**：2 颗 M2×4 固定在同一内侧壁的导轨
4. **喇叭**：贴内壁或先松散放置
   （顺序严格按 USB → PCA9685 → 功放 → 喇叭，后装的别挡住先装的）
5. **ESP32**：从桌面上方嵌入开孔，引脚穿过孔，从下方接杜邦线
6. **通电冒烟测试（推荐）**：确认每根线都在正确引脚上 → 上电 → 应看到 ESP32 灯亮并启动配置热点 → 正常则**断电**
7. `LampButton` 放在 `LampBase` 下方（用来从上方按 ESP32 复位键），`LampBase` 对准状态灯，2 颗 M2×8 固定
8. 回到 `assembly.md` 的 **§14** 继续；**§15 时舵机插到 PCA9685 的通道 0–4**（channel→关节的对应关系与主板方案相同）

## 5. 与方案 A 的差异 / 风险

| 项 | 方案 A（主控板） | 方案 B（模块） |
| --- | --- | --- |
| 板载保护 | 3A 自恢复保险丝 + TPS259571 eFuse（舵机限流 ~2A） | **没有** → 建议自加 5V 3A 自恢复保险丝 |
| I2C 上拉 | 板载 4.7 kΩ | 靠模块自带（一般有；不稳时补 4.7kΩ 到 3V3） |
| 焊接量 | 只焊 2 条 1×9 母座 | 分线板/线头少量焊（杜邦压接也可，但焊更可靠） |
| 新增故障点 | — | 接插件接触电阻、杜邦线质量、线束走线 |
| 面包板 | 不适用 | **只允许走信号线**，舵机 5V 大电流不要过面包板 |
| 固件 | 相同 | 相同（仅当 PCA9685 无 OE 引出时，改 `PCA9685_OE_WIRED=false` 重编） |
| 打印件 / 流程 / 验收标准 | — | 完全一致 |
