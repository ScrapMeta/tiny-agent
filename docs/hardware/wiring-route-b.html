3.5 舵机 → 通道 → 关节

PCA9685关节固件常量接线
CH0头部俯仰SERVO_HEAD每路 3 线：
橙/黄 = SIG → 通道 SIG
红 = 5V → 通道 5V（来自 V+）
棕/黑 = GND → 通道 GND
CH1颈部转动SERVO_NECK
CH2左手SERVO_HAND_LEFT
CH3右手SERVO_HAND_RIGHT
CH4身体 / 躯干SERVO_BODY
选型项必须满足
类型180° 定位型（positional）——SG90 / FS0307 / ES9051 的 180° 版本
数量5 只，同型号同批次（不同批次中位/速度差异会让动画走形）
禁止360° 连续旋转型（continuous rotation）绝对不能用
最容易买错的坑：180° 定位型 vs 360° 连续旋转型。两者外观、接线、价格几乎一样，卖家标题都写「SG90」，但 360° 型只要脉宽不等于 1500 µs 就持续单向转，而且没有机械限位。
30 秒判别：断电后用手拧舵盘——只能转约 180° 就顶住 = 定位型（对）；能无限转圈、没有尽头 = 连续旋转型（错，退货）。
另外：配网（AP）模式下固件不释放 PWM，所以装错型号时会一通电就转个不停——那不是板子坏了。

4 · 接线顺序（照这个顺序不会烧）

  1. 共地：USB GND → ESP32、PCA9685（逻辑侧）、OLED、功放，先全部接好。
  2. 信号：GP0/GP1（I2C）、GP2/GP3/GP4（I2S）、GP5（OE）、D+/D−（用分线板时）。
  3. 逻辑 3V3：ESP32 3V3 → PCA9685 VCC、OLED VCC。不要接舵机电源端。
  4. 最后接 5V：USB VBUS → ESP32 5V、PCA9685 V+、功放 Vin。此时舵机先别插。

5 · 上电前万用表自检

测量期望不对说明
PCA9685 VCC ↔ GND≈ 3.3 V接到 5V（会烧）或没接 3V3
PCA9685 V+ ↔ GND≈ 5 VV+ 没接 USB 5V，或被误接 3V3
VCC ↔ V+（断电，通断档）不通短路 → 立刻拆线，别上电
任意两处 GND 之间通（<1 Ω）漏了共地：I2C 会时通时不通
OLED 时钟线落点在 SCL（可能印 SCK）接到了 SDA 或 VCC 上
5V 轨 ↔ GND（断电）电阻不为 00 Ω = 有短路，别插电

6 · 上电后的灯语（对应你现在这块板）

现象含义处理
约每 4 秒闪 1 下（颜色可能看成绿）故障码 1：I2C 0x40 无应答，PCA9685 没找到，固件死循环，不会开热点先看板上 POWER 灯：不亮 = VCC 没接；再查 SDA=GP0、SCL=GP1、OE 有没有接、地址 0x40
每 4 秒闪 2 下故障码 2：I2S / MAX98357A 初始化失败查 GP2/3/4 → BCLK/LRC/DIN、功放 Vin 有没有 5V
蓝色常亮配网模式（RGB_PROVISIONING_B），热点已开连 TinyEngineer-XXXX → http://192.168.4.1/config
暗绿 → 熄灭待机 / 睡眠（正常）无
为什么“1 闪”看着是绿的：固件默认 rgb_order=GRB（src/settings/settings.h），新板 NVS 为空、还没走过配网向导第 4 步的 RGB 校色，红色数据落到了 G 通道。判断故障请数闪几下，别信颜色。

8 · 你手上这块 PCA9685（HW-170）怎么接

依据附件说明书（HW-170 · 16 路舵机驱动板）。它的 6P 控制排针两面各有一组、内部相通，舵机电源走 2P 螺钉端子，引脚顺序与通用模块图不同 —— 以本表为准。

8.1 6P 控制排针（从上到下）

#丝印含义接到备注
1GND模块地USB GND（共地）和 2P 端子的 V− 同一网络
2OE使能端（低有效）ESP32 GP5悬空时输出状态不确定，必须接
3SCL串行时钟ESP32 GP1与 OLED 的 SCL（或 SCK）并联
4SDA串行数据ESP32 GP0与 OLED 的 SDA 并联
5VCC逻辑供电 3–5VESP32 3V3跟 ESP32 用 3.3V，保证 I2C 电平一致
6V+舵机供电5V（与 2P 端子同一网络）侧边这针没有反接保护，见 8.2

8.2 和你图里那块通用板不一样的地方

项这块 HW-170你要怎么做
舵机电源入口2P 螺钉端子 V+ / V−；背板丝印写明：端子有防反接保护，侧边排针没有5V 走端子（红→V+，黑→V−）；不要从 6P 的 V+ 针喂舵机电流
舵机电压上限背板丝印 U+ 6V Max（说明书正文却写 5–12V）只给 5V；别信正文的 12V，SG90 也只吃 4.8–6V
逻辑供电指示POWER 灯只在 VCC 有电时亮（只接舵机电源不亮）这是最快的自检点：灯不亮 = VCC 没接 → 必然 1 闪
I2C 地址A0–A5 焊盘默认全部接地 = 0x40不用动，和固件 PCA9685_ADDRESS 一致
PWM 输出每路串了 220Ω 电阻舵机信号直接插，不要再串电阻
两面的 6P左右两组内部相通接一面即可；另一面留空或级联下一块
舵机排16 组 3 针：PWM（信号）/ U+（正）/ GND（负）CH0–CH4 接五只舵机，橙=信号、红=U+、棕/黑=GND
这块板的上电顺序：① 6P：GND → SCL/SDA/OE → VCC(3V3)　② 确认 POWER 灯亮　③ 2P 端子接 5V　④ 最后插舵机。顺序错了最容易在插舵机那一步把 5V 窜进 3.3V 域。

9 · 已踩过的坑（实测记录）

现象真实原因怎么确认怎么修
所有通道都不动，网页点了也没反应用 JSON body 调 API；v0.2.0 只认 query 参数（JSON 是仓库 main 分支后来的改动，未发版）返回 400 missing index or angle改成 /setup/servo?index=0&angle=120
一通电就单向转不停买成了 360° 连续旋转型；AP 模式又不释放 PWM，所以一直有脉冲断电手拧舵盘能无限转圈换 180° 定位型
网页面板是灰的/点不动设备还在配网模式，除 /setup/* 外接口一律 503/health 里 provisioning:true走完 Wi-Fi 向导，用 tiny-engineer.local 访问
PCA 能找到但 5 路全无输出OE 悬空（模块内部上拉 = 输出关闭）量 6P 的 OE 针对 GND，≈3.3 VGP5 → OE 补线；或临时把 OE 接地验证
舵机装好后手推很松静止 2 秒后固件主动关 PWM（正常）点动瞬间是否顶住无需处理
三个高频烧板点：① 5V 接进 ESP32 的 3V3 或任何 GPIO；② PCA9685 的 VCC 与 V+ 并在一起；③ 用 C3-Zero 自带 USB-C 的同时又从分线板供 5V（双电源对打，只能选一个供电源）。
验收顺序：暗绿初始化 → 出现 TinyEngineer-XXXX 热点 + 蓝灯常亮 → 连上开 http://192.168.4.1/config → 按 Move all to 90° 做舵机中位。装壳前别把 Wi-Fi 向导走完。
